# AnirudhNallawar.github.io

Personal robotics and embedded systems portfolio. A static site compatible with GitHub Pages.

## Files
- `index.html` — portfolio homepage
- `styles.css` — homepage styles
- `script.js` — navigation, skills carousel, and photography gallery
- `cv.html` — current printable CV, with a browser Print / Save as PDF button
- `projects/` — project pages and shared case-study content

## Content source
Updated from `Anirudh_Nallawar_CV 09_01_26.docx` in Google Drive on October 6, 2026. The CV buttons open `cv.html`; the older résumé PDF remains in the repository.

## Local preview
Run `python3 -m http.server 8765` from this directory, then open http://localhost:8765.
